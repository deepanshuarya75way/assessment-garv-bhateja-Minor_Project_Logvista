# LogVista

## AI-Based Log Investigation Framework for Cyber Forensics

LogVista is a web-based log investigation framework developed to assist in the analysis of system and security logs. The project focuses on reducing the manual effort involved in examining large amounts of log data by combining log parsing, machine learning, anomaly detection, event correlation, and timeline reconstruction.

The system takes raw log data as input, processes and analyzes individual events, identifies potentially suspicious activity, correlates related events, and presents the investigation results through a web interface.

## Problem Statement

Security logs contain important information about system activity, authentication events, network connections, errors, and other security-related events. When the volume of logs becomes large, manually examining them can be time-consuming and it can be difficult to identify relationships between events.

LogVista was developed to provide a structured workflow for processing these logs and assisting with the identification and investigation of suspicious activities.

## Main Features

* Log file upload and processing
* Log parsing and normalization
* Log type identification
* Machine learning based analysis
* Anomaly detection
* Heuristic-based threat detection
* Event correlation

## Architecture

LogVista consists of two main components:

```text
+-----------------------+
|       Frontend        |
|     React + Vite      |
+-----------+-----------+
            |
            | API Requests
            v
+-----------------------+
|       Backend         |
|        Flask          |
+-----------+-----------+
            |
     +------+------+
     |             |
     v             v
 Log Processing   ML Analysis
     |             |
     +------+------+
            |
            v
   Event Correlation
            |
            v
   Timeline Generation
```

The frontend is responsible for the user interface and visualization of investigation results. The backend handles log processing, analysis, model execution, event correlation, and API requests.

## Machine Learning

The backend contains a separate model handling layer for performing machine learning based analysis.

The current implementation includes support for:

* Network log analysis
* Windows event log analysis
* Anomaly detection
* ML model loading and prediction
* Heuristic fallback analysis
* Threat classification
* Attack-stage mapping

The system can use trained models when available and fall back to heuristic analysis for supported investigation scenarios.

## Installation

### Requirements

Make sure the following are installed:

* Python 3.10 or later
* Node.js
* npm
* Git

### Clone the repository

```bash
git clone https://github.com/Garv-m-netizen/Minor_Project_Logvista.git
cd Minor_Project_Logvista
```

## Backend Setup

Go to the backend directory:

```bash
cd backend_2
```

Create a virtual environment:

```bash
python -m venv venv
```

On Windows:

```bash
venv\Scripts\activate
```

On Linux/macOS:

```bash
source venv/bin/activate
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Run the backend:

```bash
python app.py
```

## Frontend Setup

Open another terminal and go to the frontend directory:

```bash
cd frontend
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The terminal will display the local URL generated by Vite.

## Environment Variables

The frontend uses the backend API URL through the following environment variable:

```text
VITE_API_BASE_URL
```

For local development, an example configuration is:

```env
VITE_API_BASE_URL=http://localhost:5000
```

The value should match the address and port on which the Flask backend is running.

## Investigation Process

### 1. Log Upload

The investigator uploads the log file through the frontend.

### 2. Log Processing

The backend reads the log and converts the available information into a structured format.

### 3. Analysis

The processed events are analyzed using the available machine learning models and heuristic detection logic.

### 4. Threat Detection

Suspicious or anomalous events are identified based on the analysis results.

### 5. Event Correlation

Related events are correlated to provide additional context around an incident.

### 6. Timeline Reconstruction

Correlated events are arranged chronologically to help reconstruct the sequence of activities.

### 7. Visualization

The investigation results are returned to the frontend and displayed through the dashboard.

## Deployment

The project can be deployed using a separate frontend and backend setup.

The current deployment configuration uses:

```text
Frontend  -> Vercel
Backend   -> Render
```

The repository contains `DEPLOY_VERCEL_RENDER.md` with the deployment configuration and setup instructions.

For the frontend, configure:


The backend can be deployed as a Flask application using Gunicorn.

## Research and Development

LogVista is being developed as a project for studying the application of machine learning and automated analysis techniques to cybersecurity log investigation.

The current implementation focuses on building the investigation pipeline and integrating different analysis techniques rather than replacing a complete SIEM or professional digital forensic platform.

## Limitations

The results produced by machine learning and heuristic detection methods should be treated as investigation assistance rather than definitive forensic conclusions.

Detection performance can depend on:

* Log format
* Data quality
* Available trained models
* Features present in the logs
* Type of security activity being investigated

The original log data should be retained and manually verified when conducting an actual forensic investigation.
